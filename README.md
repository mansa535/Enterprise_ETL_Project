# Enterprise ETL Pipeline & Data Warehouse Synchronizer

## Project Description

A production-level ETL pipeline that extracts business data from third-party APIs, transforms and validates the data, and loads it into a centralized PostgreSQL data warehouse.

## Project Workflow

API Sources
→ Data Extraction
→ Raw Data Storage
→ Data Transformation
→ Data Validation
→ PostgreSQL
→ Airflow Automation
